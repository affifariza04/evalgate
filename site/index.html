evalgate · live demo

Unit tests for prompts.
A gate for your CI.

Write eval cases in YAML, grade replies with cheap rules plus an LLM judge, compare two prompt versions with paired statistics, and fail the pull request when quality or policy regresses.

The story in this demo

v1 · baseline9 / 12

Correct on policy, but wordy, answers Indonesian customers in English and is vague on grind size.

v2 · "be warm and generous"9 / 12

Same headline score, yet it now promises refunds on opened bags and invents a discount code. The gate blocks it.

v3 · firm policies, same tone12 / 12

Keeps v2's fixes, restores the policy guardrails. Gate passes.

An average pass rate would have called v1 → v2 a tie. Per-case pairing and critical checks are what catch it.

In CI

- run: uv run evalgate run evals/suite.yaml -o candidate.json
- run: uv run evalgate compare evals/suite.yaml baseline.json candidate.json --html report.html
  # exit code 1 blocks the merge; a Markdown summary lands in the job summary

The replies in this demo are hand-written fixtures replayed from a cassette, so the page and CI need no API key. Pointing the suite at Claude with --record runs the same checks on real completions.
